## 📖 Overview
This project aims to analyze customer behavior in a Telecommunications company to predict **Churn** (customers leaving the service). Using Python and Machine Learning, I identified the key factors that drive customers to stay or leave, providing actionable insights for the business.

## 📁 Project Structure
- `Data/`: Contains the raw dataset (Telco-Customer-Churn).
- `Visuals/`: High-quality charts generated during the analysis.
- `Telecom_Churn_Analysis.ipynb`: The main notebook covering Data Cleaning, EDA, and Modeling.

- **Languages:** Python

## 💡 Recommendations
- Promote **Long-term contracts** (One year / Two year) as they show significantly lower churn.
- Focus on **Tech Support** and **Online Security** as value-added services that increase loyalty.
- Target high-risk customers (High monthly charges + Short tenure) with personalized offers.
